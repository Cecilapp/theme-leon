---
title: Front matter
description: Variables de page prises en charge par Léon.
---
| Variable | Description |
| -------- | ----------- |
| `description` | Affichée sous le titre. |
| `eyebrow` | Texte au-dessus du titre (le nom du groupe par défaut). |
| `sidebar_title` | Titre dans la barre latérale. |
| `collapsed` | Replie une section imbriquée dans la barre latérale. |
| `toc` | `false` masque la table des matières. |
| `copypage` | `false` masque le bouton « Copier la page ». |
| `updated` | Date de « Mis à jour le ». |
| `cards` | Cartes de la page d'accueil (`title`, `description`, `url`). |
