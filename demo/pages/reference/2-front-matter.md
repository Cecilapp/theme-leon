---
title: Front matter
description: Page variables supported by Léon.
---
| Variable | Description |
| -------- | ----------- |
| `description` | Displayed under the title. |
| `eyebrow` | Text above the title (the group name by default). |
| `sidebar_title` | Title in the sidebar. |
| `collapsed` | Collapses a nested section in the sidebar. |
| `toc` | `false` hides the table of contents. |
| `copypage` | `false` hides the "Copy page" button. |
| `updated` | "Last updated" date. |
| `cards` | Cards of the home page (`title`, `description`, `url`). |
