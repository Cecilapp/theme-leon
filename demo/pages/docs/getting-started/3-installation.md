## With Composer

```bash
composer require cecil/theme-leon
```

Composer installs Léon in `themes/leon`, and its dependencies in `themes/flexsearch` and `themes/darkmodetoggle`.

## Manually

Download the [latest release](https://github.com/Cecilapp/theme-leon/releases/latest/) and uncompress it in `themes/leon`.

:::warning
Theme dependencies are not resolved automatically: download the [FlexSearch](https://github.com/Cecilapp/theme-flexsearch) and [Dark mode toggle](https://github.com/Cecilapp/theme-darkmodetoggle) themes too.
:::
