## Avec Composer

```bash
composer require cecil/theme-leon
```

Composer installe Léon dans `themes/leon`, et ses dépendances dans `themes/flexsearch` et `themes/darkmodetoggle`.

## Manuellement

Téléchargez la [dernière version](https://github.com/Cecilapp/theme-leon/releases/latest/) et décompressez-la dans `themes/leon`.

:::warning
Les dépendances de thèmes ne sont pas résolues automatiquement : téléchargez aussi les thèmes [FlexSearch](https://github.com/Cecilapp/theme-flexsearch) et [Dark mode toggle](https://github.com/Cecilapp/theme-darkmodetoggle).
:::
